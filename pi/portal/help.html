How to use the Ark

One page, plain words. If you can use a website, you can use this.

What this box is

The Ark is a small computer that carries a library. It makes its own Wi-Fi network, so phones, tablets and laptops can read everything on it without any internet at all. Reading, playing and sharing need no account. (The owner has a private sign-in for looking after the box, and a game save can have a name of its own; neither is needed to read or play.)

If a “Sign in to Wi-Fi” window opens

That window is the phone trying to be helpful. It is not a real sign-in page and you do not need an account. Two things to know:

  • Some buttons inside that window do nothing. That is normal. Close the window and open a normal browser instead.
  • Type ark.lan into the address bar. The full address is http://ark.lan — the “http://” part matters.
Two addresses always work: http://ark.lan and http://10.42.0.1. If one does not open, try the other.

What is inside

  • Offline Library Encyclopedias, medical references and question-and-answer archives. Pick a collection, then use its search box.
  • Books Full-length books. Tap a cover to read it in the browser or to download it.
  • Manuals & Guides Short pages written for a phone screen: water, first aid, power, plumbing, wiring.
  • Pocket Cards to Print One page each. Print them and tape them inside a cupboard door.
  • Message Board Leave a note for the next person. Anyone on the network can read and post.
  • File Box Share a file with everyone. Tap “Choose a file”, then “Put it in the box”.
  • Games Small games that run right here. Tap one and play; no name is needed.

Reading on a phone

Everything is built for a small screen: big buttons, dark background so it does not glare at night, and text you can read without zooming. Pages you open in the Offline Library have their own back button — use your phone’s back arrow to come back here.

Keeping it working

  • Leave the box plugged in. It draws about as much power as a phone charger.
  • The Wi-Fi has no password on purpose. Anyone nearby can read the library — that is the point. Do not keep secrets in the File Box.
  • Big collections keep arriving on their own when the box finds an internet connection. You do not have to do anything; new material simply appears.

Still stuck? Try http://10.42.0.1 instead of ark.lan, and make sure you are joined to the network called The-Ark-Offline.
